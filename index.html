Testmodus

Alle spielen an diesem Gerät. Über die Leiste oben wechselst du zwischen den Ansichten der Spieler.

So funktioniert's
  1. Einer erstellt einen Raum und schickt den Link an die anderen.
  2. Jeder schreibt für einen Mitspieler eine geheime Figur auf.
  3. Du siehst die Figuren aller anderen, nur deine eigene nicht.
  4. Wer dran ist, stellt eine Ja/Nein-Frage. Die anderen stimmen per Knopf ab.
  5. Glaubst du, es zu wissen? Drück „Ich weiß es!“. Wenige Fragen = viele Punkte.
